## Lo que aprendí

- Aprendí a clonar un repositorio de GitHub y trabajar en su carpeta desde VS Code.
- Usé `git status`, `git add`, `git commit` y `git push` para revisar, registrar y publicar cambios.
- Probé la variable de entorno `APP_MODE` con los valores `desarrollo` y `prueba`.
- Agregué `.env` a `.gitignore` para excluir la configuración local.
- Practiqué `git rm --cached` con un archivo de prueba para dejar de rastrearlo sin borrar la copia local.
- Aprendí a separar el trabajo en `main`, `develop` y una rama `feature/descripcion`, y a proponer los cambios mediante un Pull Request hacia `develop`.
